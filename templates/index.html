How RSA-2048 Key Pairs Work

Public Key

Shared openly. Used to encrypt data for the owner and to verify their signatures.

Private Key

Kept secret. Used to decrypt received data and create digital signatures. Never shared.

2048-bit Security

Provides 112-bit equivalent security strength. Computationally infeasible to crack with current technology.

How Detection Works

Integrity — SHA-256

After decryption, the file's SHA-256 hash is recomputed and compared to the stored original. Even a single bit change produces a completely different hash value.

Authentication — Digital Signature

The sender signs the file hash with their RSA private key. The receiver verifies using the sender's public key. An invalid signature means the sender cannot be trusted.
