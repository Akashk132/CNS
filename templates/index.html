How RSA-2048 Key Pairs Work

Public Key

Shared openly. Used to encrypt data for the owner and to verify their signatures.

Private Key

Kept secret. Used to decrypt received data and create digital signatures. Never shared.

2048-bit Security

Provides 112-bit equivalent security strength. Computationally infeasible to crack.

How it Works

Pixel-Level Encryption

The raw pixel bytes (RGB channels) of the image are extracted and encrypted using AES-256-CBC. The resulting ciphertext bytes are then mapped back to pixels — creating a visually random "noise" image.

Perfect Decryption

With the AES key and IV, the original pixels are recovered byte-for-byte. The restored image is identical to the original.

Root CA

Self-signed certificate that is trusted by default. Signs all subordinate certificates. Kept offline in production.

End-Entity Certificate

Issued by the CA to a specific entity (e.g. a website, user, or server). Contains their public key.

Verification

Anyone with the CA's public key can verify that the entity's certificate was legitimately issued.
