How RSA-2048 Key Pairs Work

Public Key (e, n)

Shared openly. Modulus n = p × q, public exponent e = 65537. Used to encrypt data for the owner and verify their signatures.

Private Key (d, n)

Kept secret. Derived via Extended Euclidean Algorithm: d ≡ e⁻¹ mod φ(n). Used to decrypt ciphertext and create signatures.

2048-bit Security

Factoring modulus n requires ~2¹¹² operations—computationally infeasible with classical computers.

Educational Deep Dive: The 5-Step RSA-2048 Derivation ▼ Expand Details

1. Prime Selection (p and q)

Two 1024-bit primes chosen using Miller-Rabin test across 64 rounds to guarantee composite probability < 2⁻¹²⁸.

2. Semiprime Modulus (n = p × q)

The 2048-bit modulus n defines the modular domain ℤ/nℤ for all cryptographic operations.

3. Euler's Totient (φ(n))

φ(n) = (p - 1)(q - 1). Counts integers up to n coprime to n.

4. Public Exponent (e = 65537)

The Fermat prime F₄ (2¹⁶ + 1 = 10000000000000001₂), allowing extremely fast modular exponentiation with minimal multiplications.

5. Private Exponent (d ≡ e⁻¹ mod φ(n))

Calculated using the Extended Euclidean Algorithm such that (e × d) ≡ 1 mod φ(n).

1. SHA-256 Digest

The entire file is hashed chunk-by-chunk to produce a fixed 256-bit fingerprint. Guarantees Integrity.

2. RSA Digital Signature

The file hash is encrypted with the Sender's private key (PKCS#1 v1.5). Guarantees Authentication & Non-Repudiation.

3. AES-256 Session Key

A cryptographically secure random 256-bit key and 16-byte IV are generated on-the-fly for bulk file encryption.

4. AES-256-CBC Stream

The file is encrypted at multi-megabyte/sec hardware speeds using Cipher Block Chaining. Guarantees Confidentiality.

5. RSA-OAEP Key Wrap

The 32-byte AES key is encrypted with the Receiver's RSA public key using Optimal Asymmetric Encryption Padding.

6. Cryptographic Bundle

The ciphertext, wrapped key, IV, signature, and metadata are combined into a transmission package.

Educational Guide: How LSB Spatial-Domain Steganography Works ▼ Expand Details

1. 32-bit Header Length

The secret text length is packed as a 4-byte big-endian unsigned integer (uint32) prepended to the payload.

2. Bitwise Injection

Each byte is converted to 8 binary bits. Pixel channels are masked using channel' = (channel & ~1) | bit.

3. Perceptual Invisibility

Modifying the lowest bit alters RGB intensity by at most ±1 unit out of 256. Human eyes cannot detect luminance differences below ΔE < 1.0.

AES Round Mechanics Explained

Step 0: 4x4 State Matrix Mapping

AES groups 16 bytes (128 bits) of data into a 4x4 matrix arranged in column-major order: byte 0 at [0,0], byte 1 at [1,0], byte 2 at [2,0], and byte 3 at [3,0].

Initial AddRoundKey

Before round 1, the plaintext state matrix is XORed bit-by-bit with the initial 128-bit master key. This ensures data is obscured before entering round transformations.

Why Cipher Mode Matters: Electronic Codebook (ECB) vs Cipher Block Chaining (CBC)

ECB encrypts each 16-byte block independently with the key. If two blocks have identical pixels, they produce identical ciphertext, causing structural patterns and silhouettes to leak! CBC solves this by XORing each block with the previous ciphertext block.

ECB Mode (Vulnerable)

Formula: C_i = Encrypt_K(P_i)

Deterministic mapping preserves identical blocks across images and documents.

ECB Entropy ~6.8 bits/byte (Pattern Leakage)
CBC Mode (Secure)

Formula: C_i = Encrypt_K(P_i ⊕ C_{i-1}) with C_0 = IV

XORing with the previous block diffuses entropy, producing pure pseudo-random white noise.

CBC Entropy ~7.999 bits/byte (Ideal White Noise)
Least Significant Bit (LSB) Pixel Decomposition

Each pixel has Red, Green, and Blue channels (0–255). Modifying the 8th bit alters the color intensity by at most 1 unit—completely invisible to the human visual system.
